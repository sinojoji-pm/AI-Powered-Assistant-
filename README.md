# AI Productivity Assistant 

Create a modern AI Productivity Assistant web application.

The application should have a clean professional blue and white theme.

The landing page should include:

• Hero section

• Navigation bar

• Four feature cards

• Footer

Title:

AI Productivity Assistant

Subtitle:

Automate workplace tasks using Artificial Intelligence.

Create four tools.

1. Smart Email Generator

Inputs:

- Recipient

- Email Purpose

- Tone (Formal, Friendly, Persuasive)

Output:

Generate a professional email.

----------------------------------

2. Meeting Notes Summarizer

Input:

Paste meeting notes.

Output:

- Summary

- Key Decisions

- Action Items

- Deadlines

----------------------------------

3. AI Task Planner

Input:

Today's Tasks

Output:

- Prioritized schedule

- Suggested working times

- Productivity tips

----------------------------------

4. AI Research Assistant

Input:

Research topic

Output:

- Summary

- Key insights

- Recommendations

----------------------------------

Each feature should have:

Input area

Generate button

Output card

Loading animation

Copy button

Responsive design

Rounded cards

Professional icons

Blue gradient buttons

----------------------------------

Include a Responsible AI section saying:

AI-generated responses may contain errors.

Always verify important information before using it professionally.

Avoid entering confidential business information.

----------------------------------
